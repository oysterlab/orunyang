# 올라가냥 (Orunyang)

두 버튼으로 끝없이 위로 오르는 귀여운 고양이 계단 오르기 캐주얼 게임.

- **올라가기 / 방향 전환** 두 버튼으로 지그재그 계단을 오른다.
- 게이지가 바닥나기 전에 리듬에 맞춰 탭 — 깔끔한 연속 탭은 **콤보**로 회복량이 늘어난다.
- **로켓 아이템**을 먹으면 위로 시원하게 부스트한 뒤, 3·2·1 카운트 후 재개.
- 배경은 집 → 지붕 → 하늘 → 노을 → 우주로 펼쳐지며, 곳곳의 친구냥이 손을 흔든다.
- 캐릭터 3종(체리·라떼·닐라) + 사진으로 '우리 냥이' 초대 기능.
